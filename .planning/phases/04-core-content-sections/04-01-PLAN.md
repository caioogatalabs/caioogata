    **2. Create `src/hooks/useScrollVideo.ts`:**
    Custom hook that maps scroll position to canvas frame drawing. Follow the rAF pattern from `useScrollReveal.ts`.
    
    Interface:
    ```typescript
    export function useScrollVideo({
      frameCount = 241,
      framePath = '/about-frames/frame-',
      frameExtension = '.webp',
      scrollHeight = 400, // vh units — total scroll zone height
    } = {}): {
      containerRef: React.RefObject<HTMLDivElement | null>;
      canvasRef: React.RefObject<HTMLCanvasElement | null>;
      progress: number; // 0-1 scroll progress through zone
    }
    ```

    Implementation:
    - On mount, preload all frame images into an `Image[]` array using `new Image()` + `src` assignment. Frame filenames: `frame-001.webp` through `frame-241.webp` (ffmpeg starts at 1, not 0).
    - Use rAF scroll listener (same `tickingRef` pattern as `useScrollReveal`).
    - `containerRef` goes on the tall scroll zone div. Compute scroll progress: `progress = clamp((scrollTop - containerTop) / (containerHeight - viewportHeight), 0, 1)`.
    - Map progress to frame index: `frameIndex = Math.floor(progress * (frameCount - 1))`.
    - Draw the corresponding `Image` to `canvasRef` using `ctx.drawImage()`. Canvas sized to image natural dimensions.
    - Return `{ containerRef, canvasRef, progress }`.
    - Respect `prefers-reduced-motion`: if enabled, show last frame statically (no scroll mapping).
    - Clean up scroll listener on unmount.
