**Step 1 — Frame extraction script** (`scripts/extract-frames.sh`):
Create a bash script that uses ffmpeg to extract WebP frames from the source video:
```bash
#!/bin/bash
# Extract WebP frames from about video hero
# Usage: ./scripts/extract-frames.sh
INPUT="about-refs/caio-about-video-hero.mp4"
OUTPUT_DIR="public/about-frames"
mkdir -p "$OUTPUT_DIR"
# Extract every frame as WebP, quality 80, resize to 1280px width
ffmpeg -i "$INPUT" -vf "scale=1280:-1" -q:v 80 "$OUTPUT_DIR/frame-%04d.webp"
echo "Frames extracted to $OUTPUT_DIR/"
echo "Total frames: $(ls $OUTPUT_DIR/frame-*.webp | wc -l)"
```
Make executable with `chmod +x`.

Then RUN the script to actually generate the frames into `public/about-frames/`. Count the resulting frames — this determines the FRAME_COUNT constant in the hook.

**Step 2 — useScrollVideo hook** (`src/hooks/useScrollVideo.ts`):
Create a custom hook following the same rAF + ref + state pattern as `useScrollReveal.ts`. The hook:

```typescript
export function useScrollVideo({
  frameCount,          // total number of frames (from extraction)
  framePath,           // path template: '/about-frames/frame-NNNN.webp'
  scrollHeight = 4,    // multiplier for container height in vh units (4 = 400vh scroll zone)
} = {})
```

Returns `{ containerRef, canvasRef, progress }`:
- `containerRef`: ref for the scroll container div (height = scrollHeight * 100vh)
- `canvasRef`: ref for the `<canvas>` element (positioned sticky inside container)
- `progress`: 0-1 scroll progress through the zone

Implementation details:
- Preload all frames into an `Image[]` array on mount using `useEffect`. Load in batches of 20 to avoid overwhelming the browser. Track loading progress.
- On scroll (rAF throttled, passive listener — same pattern as useScrollReveal):
  1. Get container's `getBoundingClientRect()`
  2. Calculate progress: `clamp(0, 1, -rect.top / (rect.height - window.innerHeight))`
  3. Map progress to frame index: `Math.floor(progress * (frameCount - 1))`
  4. Draw that frame's Image to the canvas via `canvasRef.current.getContext('2d').drawImage(images[frameIndex], 0, 0, canvas.width, canvas.height)`
- Canvas sizing: set `canvas.width` and `canvas.height` from the first loaded image's natural dimensions, then CSS `width: 100%; height: 100vh; object-fit: cover` on the canvas element.
- `prefers-reduced-motion`: skip to last frame immediately, no scroll animation.
- Clean up scroll/resize listeners on unmount.
