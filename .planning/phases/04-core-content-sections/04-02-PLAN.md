**State management:**
- `hoveredIndex: number | null` — mouse hover tracking
- `activeIndex: number | null` — keyboard focus tracking  
- `expandedIndex: number | null` — which row is expanded (toggle on click/Enter)

- Keyboard: attach `onKeyDown` to the list. Arrow Up/Down moves `activeIndex` (wrap around). Enter toggles `expandedIndex` for the active row. Esc closes expanded.

**Keyboard navigation (per D-20):**
```typescript
function handleKeyDown(e: React.KeyboardEvent) {
  const jobCount = jobs.length
  switch (e.key) {
    case 'ArrowDown':
      e.preventDefault()
      setActiveIndex(prev => prev === null ? 0 : (prev + 1) % jobCount)
      break
    case 'ArrowUp':
      e.preventDefault()
      setActiveIndex(prev => prev === null ? jobCount - 1 : (prev - 1 + jobCount) % jobCount)
      break
    case 'Enter':
      e.preventDefault()
      if (activeIndex !== null) {
        setExpandedIndex(prev => prev === activeIndex ? null : activeIndex)
      }
      break
    case 'Escape':
      e.preventDefault()
      setExpandedIndex(null)
      setActiveIndex(null)
      break
  }
}
```
