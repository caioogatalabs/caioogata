**SVG Line Calculation (per D-25):**
Use `useEffect` + `useCallback` with a resize observer to measure positions:
- For each skill with projectSlugs, find the skill element (`data-skill` attribute) and each connected project element (`data-project` attribute)
- Get their `getBoundingClientRect()` relative to the SVG container
- Calculate a bezier curve path from the right edge of the skill item to the left edge of the project item:
  ```
  const midX = (startX + endX) / 2
  d = `M ${startX} ${startY} C ${midX} ${startY}, ${midX} ${endY}, ${endX} ${endY}`
  ```
- Store as `{ path: string, skillName: string, projectSlug: string, isActive: boolean }[]` in state
- Recalculate on window resize (debounced 150ms)

function levelToValue(level: string): number {
  switch (level) {
    case 'Expert': return 1.0
    case 'Advanced': return 0.75
    case 'Proficient': return 0.5
    case 'Familiar': return 0.25
    default: return 0.5
  }
}
