      - Expert = 95% width, Advanced = 75%, Proficient = 55%, Familiar = 35%
      - Bar: `h-0.5 bg-fill-primary` (yellow) or `bg-text-primary` (white).

    - Use `useRef` + `useEffect` to measure DOM positions of skill items and project items after render.
    - Draw SVG `<path>` elements (bezier curves) connecting each skill to its mapped projects.
    - Line styling: `stroke: var(--color-border-default)`, `strokeWidth: 1`, `fill: none`.
    - Use cubic bezier curves: from skill item right edge → curve right → to project item left edge.
    - SVG positioned `absolute` between the two grid columns, full height of the map zone.
    - Recalculate positions on window resize (debounced).

    **Bidirectional hover highlighting (per D-26):**
    - State: `highlightedSkill: string | null` and `highlightedProject: string | null`.
    - Hover a skill → set `highlightedSkill`. Its connected SVG lines get `stroke: var(--color-fill-primary)` (yellow) + `strokeWidth: 2`. Connected projects get full opacity. Everything else dims to `opacity: 0.2`.
    - Hover a project → set `highlightedProject`. Find all skills that have this project in `projectSlugs`. Highlight those skills + their lines. Everything else dims.
    - No hover → all items and lines at full opacity.
    - Transition: `opacity 0.3s ease, stroke 0.3s ease`.

    **SVG line animation on scroll (per D-29, discretionary):**
    - On `useInView` trigger, SVG lines can animate using `stroke-dasharray` / `stroke-dashoffset` for a draw-in effect.
    - `stroke-dashoffset` transitions from full length to 0 over 1s with stagger per line.

    **Mobile responsive (Claude's discretion):**
    - On mobile (below `md`), hide SVG lines. Stack skills and projects vertically.
    - Skills list shows full with progress bars.
    - Projects list shows below with connected skills listed as tags under each project.
