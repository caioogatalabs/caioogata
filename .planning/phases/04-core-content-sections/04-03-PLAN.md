    Add SVG connecting lines and bidirectional hover highlighting to the existing SkillsSection component.

    **SVG connecting lines (per D-25):**
    - Add a `useRef` for the relationship map container and refs for measuring skill/project item positions.
    - Use `useEffect` (runs after render) to measure DOM positions of elements with `data-skill-id` and `data-project-slug` using `getBoundingClientRect()`.
    - Draw an absolutely positioned `<svg>` element between the two grid columns, full height of the map zone. Position: `absolute inset-0 pointer-events-none`.
    - For each skill with `projectSlugs`, draw `<path>` elements (cubic bezier curves) connecting the skill item to each mapped project item.
    - Line styling default: `stroke: var(--color-border-default)`, `strokeWidth: 1`, `fill: none`.
    - Bezier curves: from skill item right edge -> curve right -> to project item left edge. Use cubic bezier with control points offset horizontally for smooth curves.
    - Recalculate positions on window resize (debounced with 200ms).
    - Hide SVG on mobile: `className="hidden md:block"` on the SVG element.

    **Bidirectional hover highlighting (per D-26):**
    - Add state: `highlightedSkill: string | null` and `highlightedProject: string | null`.
    - Add `onMouseEnter` / `onMouseLeave` handlers to skill items (`setHighlightedSkill`) and project items (`setHighlightedProject`).
    - When `highlightedSkill` is set:
      - Its connected SVG paths get `stroke: var(--color-fill-primary)` (yellow) + `strokeWidth: 2`.
      - Connected projects get full opacity. Everything else dims to `opacity: 0.2`.
    - When `highlightedProject` is set:
      - Find all skills that have this project slug in their `projectSlugs`. Highlight those skills + their SVG paths. Everything else dims.
    - When nothing is highlighted: all items and lines at full opacity.
    - Transition: `transition: opacity 0.3s ease` on skill items, project items, and SVG paths.

    **prefers-reduced-motion:**
    - Detect via `window.matchMedia('(prefers-reduced-motion: reduce)')`.
    - When reduced motion is preferred:
      - SVG line draw animation (`stroke-dashoffset` transition): skip entirely. Lines appear instantly at full length.
      - Hover opacity transitions: instant (`transition: none` or `transition-duration: 0s`).
    - Implementation: use a `reducedMotion` boolean. Apply `style={{ transition: 'none' }}` when true.

    **SVG line draw animation on scroll entry (per D-29, discretionary):**
    - Only when reduced motion is NOT preferred.
    - On `useInView` trigger for the map container, SVG lines animate using `stroke-dasharray` / `stroke-dashoffset`.
    - Each path: set `strokeDasharray` to total path length, `strokeDashoffset` starts at total length (hidden), transitions to 0 (fully drawn).
    - Transition: `stroke-dashoffset 1s ease` with stagger per line (e.g., `transitionDelay: ${index * 0.05}s`).
    - Calculate path length via `path.getTotalLength()` in useEffect.
  </action>
