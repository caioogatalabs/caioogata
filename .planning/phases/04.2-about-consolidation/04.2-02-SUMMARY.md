## Decisions Made

- **Self-contained blocks own their own divider.** The SectionDivider is rendered inside BioBlock (not by AboutSection) so each block is a complete editorial unit. This keeps Wave 3's AboutSection orchestrator trivially simple — just `<BioBlock /><SkillsBlock />…` in order, no prop wiring for divider codes/labels.
- **No props.** BioBlock reads `content.about` directly from `en.json`, mirroring how `AboutSection` already does it. No parameterization needed for V2 single-language launch.
- **Verbatim extraction.** Per plan D-07 ("no content rewrite") and the task action's "extract verbatim" instruction, the Core Expertise list and bio paragraph styling are copied exactly from current `AboutSection.tsx` lines 138-178. The bio paragraph styling preserved here is `text-[24px] font-semibold leading-[1.3] text-text-secondary` — matching the version currently on disk in AboutSection (the working tree had been ad-hoc updated from `text-base md:text-lg text-text-primary leading-relaxed`; preserving the on-disk version was the correct interpretation since the plan says "no content rewrite, no behavior change").
- **Floating overlay stays in AboutSection.** Explicitly NOT extracted (see API Surfaces note above) — Wave 3 owns that choreography decision.
