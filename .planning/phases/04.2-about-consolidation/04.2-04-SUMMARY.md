### CELL_BORDERS encoding (per W6)

16 literal-string entries, indexed by cell. Each entry composes:
- Mobile right border: `border-r` on cells where `index % 2 === 0`
- Mobile top border: `border-t` on cells where `index >= 2`
- Desktop right border: `lg:border-r` on cells where `index % 4 < 3`, else `lg:border-r-0`
- Desktop top border: `lg:border-t` on cells where `Math.floor(index / 4) > 0`, else `lg:border-t-0` (strips mobile-only top borders at lg)
- Color token `border-border-secondary` is on every cell so any active border picks it up

The static array makes both verification (`grep -cE "^[[:space:]]*'border-border-secondary"` returns 16) and revisions trivial — there are no dynamic conditionals or template literals inside the cell render.

## Decisions Made

- **Mixed grid composition (W5 explicit):** The description sits in a 12-col `Grid` + right `GridItem span={6}`, while the logo grid intentionally spans full content width as a plain `grid-cols-2 lg:grid-cols-4` (NOT wrapped in a Grid). Rationale: editorial copy aligns to a column rhythm; the logo wall is a full-width artifact whose 4-col table dividers need viewport-wide breathing room. Empty left `GridItem` reserves the alignment slot.
- **Static lookup over inline conditionals (W6 explicit):** Per CLAUDE.md §Component Patterns ("Static class maps over dynamic Tailwind class strings"), `CELL_BORDERS` is a 16-entry literal array consumed via `CELL_BORDERS[index]`. No template literal class concatenation inside cells. Easier to verify, harder to regress.
- **Direct shortDescription read (W7 explicit):** `const shortDescription = clientsData.shortDescription as string`. No `?? clientsData.description` fallback — Wave 1 SUMMARY confirmed the field is present in both en.json and pt-br.json.
- **CLIENT_LOGOS local copy:** Duplicated verbatim from V1 `Clients.tsx` rather than imported. Keeps V1 self-contained for the `v1.caioogata.com` deploy and avoids cross-version coupling.
- **No extra animation setup beyond the existing patterns:** Each cell uses `-entrance -fade -a-${stagger}` (capped at 19) + the description gets `-entrance -slide-up -a-0` — both standard from CLAUDE.md §Animation System.
- **`useInView` ref placed on the inner content wrapper, not the outermost block div:** Matches the V2 pattern where `-inview` propagates to descendant `-entrance` children. The `SectionDivider` is purely structural (no entrance) so it sits outside the observed wrapper.
