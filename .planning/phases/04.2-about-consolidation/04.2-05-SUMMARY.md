### getSortYear / getDisplayYear helpers (private)

```typescript
function getSortYear(yearStr: string): number {
  const match = yearStr.match(/\b(19|20)\d{2}\b/g)
  if (!match || match.length === 0) return 0
  return Math.max(...match.map(Number))
}

function getDisplayYear(yearStr: string): string {
  const sortYear = getSortYear(yearStr)
  return sortYear > 0 ? String(sortYear) : yearStr
}
```

Both helpers are file-private (not exported). Wave 2 plans that need similar logic (none currently expected) should duplicate, not import, to maintain block independence.

## Decisions Made

- **Field order: institution → degree → location → note.** Institution leads because the institution name is the recognizable brand anchor for a viewer scanning the timeline (e.g., "UNOESTE", "Miami Ad School", "Udacity"). Degree is the secondary line. Location follows in mono as quasi-metadata. Note appears last with `mt-2` to give the optional commentary room to breathe.
- **Year typography: `font-mono text-sm text-text-tertiary`.** Mono evokes a timeline stamp and pairs naturally with the `1.4 / Education` divider's mono code. Tertiary text keeps it visually quiet so the institution leads the row.
- **Year width: 2-of-12 columns on desktop and tablet; full width above info on mobile.** A 2/12 column gives room for "2026" without crowding the info column on tablet. Mobile reflows to a single column for readability.
- **Padded shell `py-16 md:py-24 lg:py-32`.** Generous editorial vertical breathing matching the BioBlock pattern (D-29 — entrances + visual hierarchy without cramped feel).
- **No card backgrounds, no `border-dotted`, no `rounded-*`.** D-21 explicit: V2 ditches V1's dotted card aesthetic. Only `border-t border-border-secondary` between rows.
