    ```typescript
      frameCount = 241,
      framePath = '/about-frames/frame-',
      frameExtension = '.webp',
      scrollHeight = 400, // vh units -- total scroll zone height
    } = {}): {
      containerRef: React.RefObject<HTMLDivElement | null>;
      canvasRef: React.RefObject<HTMLCanvasElement | null>;

    }
    ```

    - Draw the corresponding `Image` to `canvasRef` using `ctx.drawImage()`. Canvas sized to image natural dimensions.
    - Return `{ containerRef, canvasRef, progress }`.

## About Hero — Refined Layout (2026-04-19)

The About hero was refined from the original full-viewport scroll video to match the ProjectHero pattern with synchronized content transitions.

### Hero Structure

```
div (200vh scroll container — drives video progress 0→1)
└── div.sticky.top-0.relative (content-driven height, NOT h-screen)
    ├── canvas.absolute.inset-0 (video frames, objectPosition: center bottom)
    ├── div.absolute.inset-0.bg-bg opacity-0.7 (overlay — see Video Background Overlay Pattern in CLAUDE.md)
    └── div.relative.z-10
        ├── div.pt-8/10/12 → StickyLogoBar (transparent, video shows through)
        └── div.pt-32/40/48.pb-8/10/12 (same padding as ProjectHero text section)
            └── Grid 4-8
                ├── span=12: label "ABT_2026 // ABOUT" (mono, tertiary)
                ├── span=4: empty
                └── span=8: headline 48px (scroll-driven slide-up exit)
```

### Scroll-Driven Transitions (synced to useScrollVideo progress 0→1)

| Element | Enter | Visible | Exit |
|---------|-------|---------|------|
| Headline | always visible | 0–45% | slides up + fades out 45–55% |
| Core Expertise | slides up + fades in 50–60% | 60–85% | fades out 85–95% |

### Core Expertise — Fixed Overlay

Core Expertise renders as `position: fixed` in the dark viewport area below the hero (bottom-aligned). Uses same 6-6 grid as editorial zone. Opacity/transform driven by video scroll progress — NOT IntersectionObserver.

- **Appears** when headline exits hero (scroll 50–60%)
- **Fades out** before video ends (scroll 85–95%)
- **pointerEvents: none** when opacity is 0

### Editorial Content Zone (after hero)

- Grid 6-6 (left empty, right bio)
- Bio paragraphs with `-entrance -slide-up` stagger
- Pull quotes removed (content repetition with headline/expertise)
- Enters normal scroll flow after video scroll container ends

### Key Rules

- Video scroll container height: `200vh` — do not change without testing transition timing
- Overlay opacity: `0.7` (70%) — documented pattern in CLAUDE.md
- Video objectPosition: `center bottom` — aligned by base
- Headline text matches ProjectHero: `text-[48px] leading-[1.15] tracking-[-0.96px]`
- Core Expertise styling: V1 vertical list structure (border-t dividers) with V2 tokens (font-sans, text-text-primary, border-border-secondary)
