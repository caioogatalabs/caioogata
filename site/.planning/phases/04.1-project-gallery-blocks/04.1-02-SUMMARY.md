## Accomplishments
- Created useScrollStick hook following useScrollExpand architecture (rAF ticking guard, prefers-reduced-motion, scroll/resize listeners)
- Built ProjectGalleryFullBleed with 100vw background bleed, 60% opacity overlay, and centered foreground with useScrollReveal entrance
- Built ProjectGalleryStick with scroll-pinned sticky gallery (slideCount * 100vh container, crossfade opacity from hook) and mobile vertical stack fallback
- Wired both new gallery types into ProjectPageShell SectionBlock switch

## Decisions Made
- Crossfade zone = 0.2/slideCount provides proportional transition bands regardless of slide count
- Mobile fallback via matchMedia listener enables conditional hook usage (useScrollStick always called but slides.length=0 guard prevents issues)
- RevealForeground sub-component isolates useScrollReveal hook from conditional rendering in parent
