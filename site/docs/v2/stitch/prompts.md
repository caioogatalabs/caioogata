# Stitch Prompts — Home

Prompts for generating Home screens in Google Stitch. Run in order.

## 1. Design System

```
Create a design system for a portfolio website with these guidelines:

- Dark mode, brutalista/minimalist aesthetic
- Primary color: yellow (similar to #FAEA4D)
- Base: near-black backgrounds
- Complementary: neutral grays
- Minimal border radius (brutalista)
- No shadows
- Headline font: grotesque with personality (bold, display use)
- Body font: clean sans-serif, good readability
- High contrast, raw, intentional feel
```

## 2. Home: Intro

```
Generate a desktop screen: Portfolio hero section.

- Full-width block, dark or yellow background
- Small overline text top: "Design Director / Design Systems / Product Design"
- Large display headline, dominant size: "Bridging brand strategy, product craft and technical workflow"
- Logo top-left, small
- Two small buttons top-right: "LLM" and language toggle "EN/PT"
- Hard visual cut at the bottom — no gradient, no fade, clear separation from next section
- Typography is the main design element, aggressive scale
- Brutalista, minimal, high contrast
```

## 3. Home: Menu

```
Generate a desktop screen: Navigation menu as tabular list.

- List of sections as rows in a table/spreadsheet style: About, Experience, Skills, Education, Clients, Philosophy, Projects
- Numbered rows (01, 02, 03...)
- Large font, structural, personality
- Navigation bar border lines wrapping top and bottom of the menu
- One row shown in hover state with inline preview — small thumbnail images appearing next to the row, highlighted with primary yellow
- The preview is a teaser only, not interactive — click goes to the full section
- Dark background, minimal, brutalista
```

## 4. Home: Projects Grid

```
Generate a desktop screen: Featured projects grid.

- 2 columns, 50/50 split, equal weight
- 4 project cards total (2 rows x 2 columns)
- Each card: project screenshot/image fills the card, title text anchored top-left corner, small arrow button (→) for navigation
- No descriptions, no tags — just image + title + arrow
- Dark card containers, clean framing
- Visual contrast with the section above
- Brutalista, minimal
```

## 5. Home: Footer

```
Generate a desktop screen: Minimalist footer.

- Full-width, dark background
- Left side: tech stack tags (Next.js, React, Tailwind, Vercel) + copyright "© 2026 Caio Ogata"
- Right side: prominent primary button "Contact" in yellow
- Compact, single row, minimal
- This footer expands upward when Contact is clicked (show closed state only)
```
